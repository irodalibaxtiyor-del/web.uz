## Klaviaturada yo‘q belgilar

Matematik belgilar, strelkalar, valyuta va yunon harflari ko‘pincha klaviaturada bo‘lmaydi. Ularni entity nomi yoki kodi bilan yozish mumkin.

## Matematik belgilar

| Belgi | Entity     | Kod       |
| ----- | ---------- | --------- |
| ∀     | `&forall;` | `&#8704;` |
| ∑     | `&sum;`    | `&#8721;` |
| √     | `&radic;`  | `&#8730;` |
| ∞     | `&infin;`  | `&#8734;` |
| ≠     | `&ne;`     | `&#8800;` |
| ≤     | `&le;`     | `&#8804;` |
| ≥     | `&ge;`     | `&#8805;` |
| ×     | `&times;`  | `&#215;`  |
| ÷     | `&divide;` | `&#247;`  |

```html
<p>Agar x &ne; 0 bo‘lsa, &radic;x &ge; 0 va x &times; 2 &le; &infin;.</p>
```

## Yunon harflari

| Belgi | Entity    |
| ----- | --------- |
| α     | `&alpha;` |
| β     | `&beta;`  |
| π     | `&pi;`    |
| Ω     | `&Omega;` |

```html
<p>Aylana uzunligi: 2&pi;r</p>
```

## Strelkalar

| Belgi | Entity   |
| ----- | -------- |
| ←     | `&larr;` |
| →     | `&rarr;` |
| ↑     | `&uarr;` |
| ↓     | `&darr;` |

```html
<a href="index.html">&larr; Orqaga</a> <a href="2-dars.html">Keyingi dars &rarr;</a>
```

## Boshqa foydali belgilar

| Belgi | Entity    | Tavsif                  |
| ----- | --------- | ----------------------- |
| ©     | `&copy;`  | mualliflik huquqi       |
| ®     | `&reg;`   | ro‘yxatdan o‘tgan belgi |
| ™     | `&trade;` | savdo belgisi           |
| €     | `&euro;`  | yevro                   |
| £     | `&pound;` | funt                    |
| ¥     | `&yen;`   | iyena                   |
| °     | `&deg;`   | daraja                  |

```html
<p>Bugun +25&deg;C, kurs: 1 &euro;</p>
```

> O‘zbek so‘mining alohida Unicode belgisi yo‘q, shuning uchun odatda “so‘m” deb yoziladi.

## Xulosa

- Klaviaturada yo‘q belgilar entity nomi (`&pi;`) yoki kodi (`&#960;`) bilan yoziladi.
- Matematik belgilar, strelkalar, valyutalar va yunon harflari uchun tayyor nomlar bor.
