## Hammasini birlashtirish

Kurs davomida portfolioning har bir qismini alohida yasadingiz. Yakuniy mashqda ular bitta sahifada birlashadi: yopishqoq header, bo‘limlarga to‘g‘ri o‘tish, loyihalar to‘ri, bir xil tugmalar va aloqa formasi.

## Nashrdan oldingi ro‘yxat

- [ ] Ism, kimligingiz va asosiy tugma birinchi ekranda.
- [ ] 3–6 ta eng yaxshi loyiha, har birida jonli va kod havolasi.
- [ ] Kamida bitta batafsil case study.
- [ ] Aloqa yo‘llari ishlaydi (formani o‘zingizga yuborib ko‘ring).
- [ ] 320px dan 1920px gacha buzilmaydi.
- [ ] Klaviatura bilan to‘liq boshqariladi.
- [ ] Lighthouse: har yo‘nalishda 90+.
- [ ] `<title>`, tavsif, Open Graph, favicon.
- [ ] Imlo xatolari yo‘q — matnni kimgadir o‘qitib chiqing.

## Qayerga joylash

Statik sayt (HTML, CSS, JS) uchun bepul variantlar ko‘p:

| Xizmat                       | Qanday                                                                     |
| ---------------------------- | -------------------------------------------------------------------------- |
| **GitHub Pages**             | Kodni GitHub’ga yuklaysiz, sozlamalarda Pages’ni yoqasiz → `ism.github.io` |
| **Netlify / Vercel**         | GitHub omboriga ulanadi, har o‘zgarishda avtomatik yangilanadi             |
| **WEBDIZAYN.UZ portfoliosi** | Platformadagi bajarilgan ishlaringizdan ochiq portfolio sahifasi           |

O‘z domeningiz (`aziza.uz`) bo‘lsa — yanada professional. Domen xizmatida DNS yozuvini sozlab, hosting xizmatiga ulaysiz.

## Kod ham portfolio

Ish beruvchi GitHub’ingizga ham qaraydi. Portfolio sayti kodining o‘zi toza, izohli va tartibli bo‘lsin: ma’noli klass nomlari, tokenlar, README fayli (nima, qanday ishga tushiriladi, qaysi texnologiyalar).

## Portfolio — tirik hujjat

Yangi yaxshi loyiha qilsangiz — eng zaifini olib tashlab, yangisini qo‘shing. Yiliga bir-ikki marta dizaynni ham yangilab turing. Eskirgan portfolio (oxirgi loyiha uch yil oldin) qiziqishni so‘ndiradi.

## Keyingi qadam

Kursni tugatdingiz. Endi o‘z haqiqiy portfolioingizni yasang, nashr qiling va havolasini o‘qituvchingizga ko‘rsating. Platformadagi “Portfolio” bo‘limida bajargan mashq va topshiriqlaringizdan ochiq sahifa yasash ham mumkin.

Mashqda portfolioning asosiy qismlarini yakuniy sahifada birlashtirasiz.
